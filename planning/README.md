# ŠPARKO — začetni načrt in UI materiali

Glavni dokument: planning/MVP-BUILD-PLAN.md
Vizualna smer: assets/ui/sparko-ui-direction.png (predogled) in .svg (vektorski vir).

To je pripravljalni paket, ne delujoča aplikacija. Ni bilo objave na Vercel.

V assets/products so štiri originalne produktne slike iz PDF-strani 5.
V assets/references so nespremenjene kopije štirih uporabnikovih referenc.
V assets/ui so oblikovni žetoni, ikone in statična tabla treh pogledov.
Ikone so SVG simboli; pri uporabi nastavite fill="none", stroke="currentColor",
stroke-width="1.8", stroke-linecap="round" in stroke-linejoin="round".

planning/seed-products.sample.json vsebuje štiri začetne, sploščene zapise.
Končno shemo Product/Offer/Placement določa načrt. Celotnega 30-izdelčnega
indeksa še ni. Cene in slike so preverjene na strani 5. Veljavnosti brez
potrditve ostanejo null. Pravokotnike pred uporabo preverite pri povečavi.
Nekatere originalne slike imajo belo podlago; ne gre za nove generirane embalaže.

work vsebuje izpis besedila, pregledane strani in izdelovalni skript oblikovne
table. Ti materiali niso končni uporabniški podatki. Izvorni PDF ostaja v korenu.
